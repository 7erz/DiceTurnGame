# DiceTurnGame

[토이 프로젝트: 턴제 주사위 RPG 프로토타입 구현]

상태 머신 기반 턴 로직: Enum을 활용해 플레이어의 주사위 굴림, 액션, 적의 턴으로 이어지는 페이즈(Phase) 전환을 엄격하게 관리하는 게임 루프를 구현

이벤트 주도 아키텍처: Action과 UnityEvent를 활용해 핵심 전투 로직과 UI 업데이트 로직을 분리, 클래스 간의 결합도를 낮추는 옵저버 패턴을 적용

프로토타이핑과 빠른 검증: 덧셈/곱셈 등 부호 주사위와 스킬 데미지를 연동하는 전투 시스템을 구현했으나, 기획적 밸런스와 플레이 템포의 근본적인 한계를 빠르게 파악하고 과감히 폐기하며 빠른 프로토타이핑의 중요성을 체감했습니다.
